## 中文介绍

**择天易数**是由台湾专业命理师择天老师开发的易数占卜工具，结合传统易学与现代设计，提供简洁直观的占卜体验。

### ✨ 功能特点

- 🎴 **易数占卜** — 传统易数起卦方式
- 📱 **响应式设计** — 完美适配手机和电脑
- 🎨 **精美UI** — 深青墨色+古铜金配色，传统与现代融合
- 🔮 **详细解读** — 卦象含义与生活指引
